== Назначение

Этот Git-версионируемый manifest является integration contract между текущим
checkout Zettelkasten и внешним OpenClaw skill state. Он не копирует содержимое
`SKILL.md`, а фиксирует точную совместимую редакцию, mapping на top-level script
и политику Detailed Note.

`operational` означает one-to-one mapping на `.scripts/zt-*.zsh` и обязательную
активную Detailed Note. `meta` означает domain, routing или inspection workflow
без собственного top-level CLI operation; Detailed Note для него необязательна.

== Правила обновления

. Изменить managed skill только через Skill Workshop.
. После применения получить SHA-256 активного `SKILL.md`.
. Обновить соответствующую строку manifest и Detailed Note policy.
. Запустить `.scripts/zt-skills-review.zsh`.
. Не считать изменение завершённым до совпадения runtime state и manifest.
