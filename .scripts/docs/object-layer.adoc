= Object Layer основного движка
:revdate: 2026-08-29
:toc:

== Назначение

`.scripts/objects/` — нейтральный API создания постоянных UUID-документов.
Он является частью движка и не реализует Zettelkasten policy.

== Dependency graph

[source,text]
----
objects -> lib
plugin  -> objects
plugin  -> lib
----

`lib -> plugin` и `objects -> plugin` запрещены.

== Constructors

[cols="1,1"]
|===
|Файл |Экспортируемая функция

|`note-create.zsh` |`zk_note_create`
|`memo-create.zsh` |`zk_memo_create`
|`todo-create.zsh` |`zk_todo_create`
|`diary-create.zsh` |`zk_diary_create`
|`topic-create.zsh` |`zk_topic_create`, `zk_topic_write`
|===

Каждый constructor создаёт `notes/UUID.adoc`, записывает обязательные metadata
и печатает basename в stdout. Note, Memo и Todo принимают дополнительные
header-атрибуты после их валидации. Обязательные metadata переопределять нельзя.

== Контракт вызова

[source,zsh]
----
source "$scripts_dir/objects/note-create.zsh"

fname="$(zk_note_create \
  "Название" \
  "note, example" \
  "Описание" \
  ":source: example")" || exit 1
----

Вызывающий слой самостоятельно решает, нужно ли открыть редактор,
зарегистрировать документ в индексе или создать связи.

== Topic writer

`zk_topic_write OUTPUT_FILE FILENAME TITLE KEY_TOPIC KEYWORDS DESCRIPTION`
позволяет host workflow сформировать Topic в staging area. UUID filename должен
быть заранее получен через `zk_new_adoc_filename`.

== Граница с плагином

Интерактивные workflow, bindings, `all-todays`, Diary chain и Workspace policy
не входят в object layer. Они документированы в
`../zettelkasten/docs/architecture.adoc`.
